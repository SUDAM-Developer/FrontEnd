# T-09 경력 홈

제공된 정상 SVG 기준. 기존 하단 탭을 유지하고 홈 헤더만 교체합니다. 로고·배너 일러스트는 SVG에서 영역을 분리했고, 텍스트·카드·진도·할 일은 React Native로 렌더링합니다.

- 개발/팀 검토 빌드만 시안의 날짜·교사·학생 예시 사용. 실제 일정 조회는 미연결
- 오늘 수업 가로 스와이프·점 선택, 교재 기록 진입, 배너 닫기, 설정·수입 이동
- 기록하기는 선택한 예시 학생과 회차를 기존 회차 기록 미리보기에 전달. 저장은 예시 동작
- 할 일 합계는 네 항목 개수의 합. 미기록 수업은 첫 예시 수업으로 이동
- PWA 안내 배너는 설치·알림 완료를 판정하지 않으며 안내 창만 표시. 알림 권한·서비스워커·실제 푸시 미연동
- 일반 빌드는 예시 학생·금액을 표시하지 않음. API 미연결 상태에서 빈 일정 표시
- 배너 닫힘은 메모리 상태로 새로고침 시 초기화

홈 API·수업 목록·할 일 필터 화면과 PWA 상태 분기는 후속 연결이 필요합니다.

## 추가 상태

- `/home?preview=empty`: 수업 없음 시안, 학생 목록 바로가기 및 할 일 표시
- `/home?preview=loading`: 3초 조회 예시. 500ms 뒤 스켈레톤 표시 후 정상 화면 전환
- `/home?preview=fast`: 100ms 조회 예시. 스켈레톤 미표시
- 위 조회 지연과 데이터는 개발/팀 검토 빌드에서만 적용
- HomeScreen의 loading이 true일 때 500ms 표시 지연 적용. 입력·조회 데이터를 실제 API로 전달하는 연결은 후속 작업
- 빈 상태 시안의 개별 할 일은 총 4건이므로 제목의 합계도 4로 계산. 원본 제목 2와 다른 것은 개별 값과 합계의 일관성을 위한 처리
- 기존 저장 화면의 로딩은 이 변경과 별개로 처리 시작 시 바로 표시

## 정상 홈 시안 갱신

캐러셀1.svg에 맞춰 다음 카드 일부를 오른쪽에 노출하고 카드 사이 간격 16을 적용합니다. 페이지 표시는 카드 너비와 간격을 합친 이동 거리로 계산합니다. 정상 할 일 목록의 외곽 테두리·동그란 배지를 제거하고, 1건 이상은 주황색, 0건은 회색 텍스트로 표시합니다. 수업 없음 상태의 목록 테두리는 기존 시안을 유지합니다.

## 첫 과외 홈 및 설치 안내

- `/home?preview=first`: 첫 과외 준비 0/4 단계 표시. 실제 완료 상태 조회는 미연결이며 단순 클릭으로 완료 수를 올리지 않음
- 학생 정보 넣기·바로 과외 만들기는 현재 구현된 `/tutoring/student`로 연결. 소개서·커리큘럼 경로는 미구현 안내
- 홈 배너에서 설치 안내 바텀시트 표시. 배경 탭·뒤로 가기·나중에로 닫기
- 알림 허용하기는 준비 중 안내만 표시. 실제 알림 권한 요청·Web Push 구독·설치 여부 판정은 미연결이며 허용 완료로 표시하지 않음
- 시안의 iOS 조건은 설치 안내 문구이며 현재 배포가 푸시를 지원한다는 의미가 아님
