# T-03 프로필 입력

새 T-03 SVG 기준으로 프로필 화면을 분리했습니다.

- 공통 TextInput, Chip, ActionButton, Loading 및 디자인 토큰 재사용
- 이름: 앞뒤 공백 제거 기준 2~10자. 초과 입력도 유지하며 주황색 입력·테두리와 “글자 수가 초과되었어요” 안내를 즉시 표시. 빈 값·한 글자·공백만·10자 초과 입력 시 완료 비활성화
- 과목: 한 개 이상 필수, 복수 선택 및 해제 가능. 이름·과목의 별표는 파란색. 390px 시안에서는 한 줄 배치, 작은 화면에서는 줄바꿈
- 완료: 유효한 이름과 한 개 이상 과목을 모두 만족할 때만 활성화. 로컬 상태를 반영하고 기존 흐름대로 `/home` 이동
- 설정의 수정: 기존 값 표시, 저장 후 설정으로 복귀
- 저장 중: 공통 로딩 및 버튼 점 표시, 입력·과목 선택·중복 제출 차단
- 저장 실패: 입력 유지 및 재시도 안내. 완료 버튼으로 재시도
- API 미확정이므로 실제 서버 저장은 연결하지 않았습니다. `onSave`로 추후 확정된 API를 연결합니다.

## 개발 미리보기

- `/dev/profile`: 빈 입력 및 검증
- `/dev/profile?scenario=loading`: 김나연·영어 선택. 완료 시 3초간 저장 중 표시 후 홈 이동
- `/dev/profile?scenario=error`: 첫 저장 실패 후 완료 버튼 재시도 시 성공

시나리오의 지연·오류는 개발 경로에만 있으며 production은 실제 프로필 경로로 전환됩니다.
