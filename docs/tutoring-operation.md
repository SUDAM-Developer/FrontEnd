# T-04 운영 방식 질문 및 유형 모달

프로필 최초 완료 → /tutoring/operation(1/5) → 유형 확인 → 학생 정보(2/5)로 연결합니다. 프로필 수정 후 설정 복귀는 유지합니다. 첫 과외 홈의 과외 만들기도 운영 방식 질문으로 이동합니다.

## 선택과 유형

- 근황 매 수업 후: 꼼꼼형, 정산 때만: 간단형, 보내지 않음: 최소형
- 숙제 알림은 사용자 확인에 따라 유형 분류에 영향을 주지 않고 요약 표와 운영 설정에 별도로 반영
- 선생님 이름은 프로필에서 읽으며 시안의 이름을 하드코딩하지 않음
- 질문의 초기 선택은 시안대로 매 수업 후·8회차 선불·숙제 보내기
- 직접 정산 회차는 기존 정산 화면과 같은 1~20 정수, 선불/후불 선택
- 이대로 시작하기에서 선택을 메모리 초안에 보관하고 기존 정산 화면(4/5)의 회차·시점에 미리 반영
- 건너뛰기는 운영 설정을 저장하지 않고 다음 단계로 이동. 기본 정책은 확정되지 않아 임의로 적용하지 않음
- 유형 모달은 배경 터치/뒤로 가기로 닫아 선택 수정 가능. 작은 화면에서는 본문 스크롤, 하단 버튼 유지

공통 TutoringFormLayout·ProgressBar·Chip·TextInput·ActionButton을 재사용합니다. 유형 그래픽만 제공된 SVG에서 분리하고 텍스트는 동적으로 표시합니다. 서버 저장·알림 발송·자동 리포트 생성은 미연결이며, 초안은 새로고침하면 초기화됩니다. 기존 학생/교재/정산/초대 화면의 API 연결은 변경하지 않습니다.
