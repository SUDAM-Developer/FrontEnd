# T-15 수입·입금 현황

## 구현 범위

- 수입 탭의 PlaceholderScreen을 실제 IncomeScreen으로 교체
- 월 교육비·입금·미수금 요약, 학생별 청구 회차·금액·입금 대기/일부 입금/입금완료 표시
- 학부모의 입금 신고와 실제 받은 금액을 구분. 신고만으로 입금완료로 전환하지 않음
- 카드 스켈레톤 로딩, 빈 목록, 오류 재시도 표시
- 원본 SVG에서 요약 그라데이션과 일러스트만 추출하고 숫자·학생 정보는 동적으로 렌더링
- 기존 하단 탭 및 인증용 메모리 상태를 재사용. 정산 리포트 및 다른 탭 화면은 수정하지 않음

## API 상태

API는 미확정입니다. `IncomeState`/`IncomeData`는 화면 모델이며 실제 계약이 아닙니다. 개발 환경에서만 확인용 데이터를 사용합니다. production은 실제 조회 연동 전까지 준비 중 안내를 표시하고 임의의 금액을 노출하지 않습니다.

월 집계와 목록은 별도로 전달할 수 있게 구분했습니다. 정상 예시는 청구 1,200,000원, 입금 400,000원, 미수금 800,000원입니다. 빈 화면 시안에도 같은 요약 금액이 남아 있어 빈 목록 미리보기는 이를 유지합니다. 실제 API 연동 시에는 조회 범위와 집계·목록 정합성을 확인해야 합니다.

부모 입금 알림·예약 알림 전송, 은행 계좌 조회, 입금 확인·금액 변경은 연결하지 않았습니다. 알림 문구와 날짜는 확인용 데이터이며 실제 예약·전송을 뜻하지 않습니다.

## 확인 경로

- `/dev/income`: 실제 수입 탭에서 정상 상태 확인
- `/dev/income?state=loading`: 고정 스켈레톤
- `/dev/income?state=empty`: 빈 목록
- `/dev/income?state=error`: 조회 실패 및 재시도

개발용 진입점은 프로필이 없으면 메모리에 미리보기 프로필을 설정해 기존 탭으로 이동합니다. production에서는 이 진입을 허용하지 않습니다. 실제 수입 탭은 `/income`이며 다른 탭의 이동 구조·공통 탭 아이콘 구현은 유지합니다.

## 공통 수입 그래픽

전달받은 graphic.svg 원본을 income-graphic.svg로 보관하고 공통 IncomeGraphic 컴포넌트로 표시합니다. 기본 100×100, 수입 요약 카드는 88×88로 적용합니다. 배치용 style과 size를 받을 수 있으며 장식 이미지이므로 접근성 읽기에서는 제외합니다. 원본의 민트색 카드·투명 효과는 보존합니다.
