# 하단 탭 아이콘

홈·일정·학생·리포트·수입 SVG를 MainTabBar에 연결했습니다. icNav.svg는 교육비/통화 모양으로 수입 탭에 매핑했습니다.

- 활성: 아이콘·글자 `#219BFF`
- 비활성: 아이콘 `#B5B9C0`, 글자 디자인 토큰의 weak 색상
- 32px 아이콘 프레임, 기존 탭 이동·다시 누르기 이벤트 유지
- SVG의 회색 면만 파란색으로 변경한 활성 에셋을 사용해 시계·리포트·통화 내부 흰색 디테일 보존
- 상단 알림 배너와 하단 탭은 별도 기능입니다. 실제 탭 화면에는 표시되며 전체 화면/개발 미리보기 경로에는 자동으로 하단 탭을 추가하지 않습니다.
